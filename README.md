# 🔗 온샘 (ONSAEM)
> 온디맨드 과외 매칭 플랫폼

## 프로젝트 구조
| 폴더 | 설명 | 기술스택 |
|------|------|----------|
| `backend/` | REST API 서버 | Spring Boot 3.x, Java 17 |
| `frontend/` | 모바일/웹 앱 | Flutter 3.x |
| `docs/` | API 및 설계 문서 | - |

## 브랜치 전략
- `main` : 배포 브랜치 (직접 push 금지)
- `develop` : 통합 개발 브랜치
- `feature/be-기능명` : 백엔드 기능 개발
- `feature/fe-기능명` : 프론트엔드 기능 개발
