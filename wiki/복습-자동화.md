# 복습 자동화 파이프라인

## 문제 상황

강의가 끝난 뒤 학생이 수업 내용을 다시 복습하려면 긴 녹화 영상을 처음부터 돌려봐야 해 비효율적이었다. 영상을 사람이 직접 요약하는 것은 확장성이 없고, 자동 요약을 PDF로 내보낼 때는 한글 폰트가 깨지거나 수식·이모지 등으로 레이아웃이 무너지는 문제가 있었다.

## 해결 방법

- 강의 **녹화 영상을 Gemini로 전사**(STT)하되, **화자와 판서 내용을 구분**해 텍스트로 정리했다.
- 전사 결과를 **5개 섹션으로 요약**하고, 이를 **한글 PDF 학습 자료로 자동 변환**했다.
- **flexmark(Markdown → HTML)** 와 **openhtmltopdf** 를 조합하고 **한글 폰트를 임베드**해 PDF 한글 깨짐을 해결했다.
- 요약 프롬프트에 **LaTeX·이모지 금지** 등 출력 제약을 두어 PDF 렌더링을 안정화했다.
- 전체 파이프라인은 스케줄러 폴링으로 비동기 처리했다(녹화 URL 확보 → 전사 → 요약 → PDF).

## 핵심 포인트

- 녹화 → 전사 → 요약 → PDF로 이어지는 무인 자동화 파이프라인 설계.
- Markdown→HTML→PDF 변환 체인에서 한글 폰트 임베드로 깨짐 문제 해결.
- 프롬프트 출력 제약(LaTeX/이모지 금지)으로 다운스트림 렌더링 안정성 확보.

## 관련 코드/도메인

- `backend/.../domain/lessonreview/` — `TranscriptScheduler`(폴링), `TranscriptService`(전사), `LessonSummaryService`(요약·PDF)
- 엔티티: `lesson_transcript`(전사 텍스트 + 요약 PDF 상태/URL)
- 프롬프트: `backend/src/main/resources/prompts/` (lesson-transcribe, lesson-summary)
- 폰트: `backend/src/main/resources/fonts/NotoSansKR-*.ttf`
