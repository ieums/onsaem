# 복습 자동화 파이프라인

## 문제 상황

강의가 끝난 뒤 학생이 수업 내용을 다시 복습하려면 긴 녹화 영상을 처음부터 돌려봐야 해 비효율적이었다. 영상을 사람이 직접 요약하는 것은 확장성이 없고, 자동 요약을 PDF로 내보낼 때는 한글 폰트가 깨지거나 수식·이모지 등으로 레이아웃이 무너지는 문제가 있었다. 또한 녹화→전사→요약을 잇는 비동기 파이프라인 특성상, 각 단계 사이의 타이밍 문제나 외부 API의 자원 제약으로 파이프라인 전체가 멈추는 사고도 여러 번 있었다.

## 해결 방법

- 강의 **녹화 영상을 Gemini로 전사**(STT)하되, **화자와 판서 내용을 구분**해 텍스트로 정리했다.
- 전사 결과를 **5개 섹션으로 요약**하고, 이를 **한글 PDF 학습 자료로 자동 변환**했다.
- **flexmark(Markdown → HTML)** 와 **openhtmltopdf** 를 조합하고 **한글 폰트를 임베드**해 PDF 한글 깨짐을 해결했다.
- 요약 프롬프트에 **LaTeX·이모지 금지** 등 출력 제약을 두어 PDF 렌더링을 안정화했다.
- 전체 파이프라인은 스케줄러 폴링으로 비동기 처리했다(녹화 URL 확보 → 전사 → 요약 → PDF).
- **녹화 파일 병합 완료 전에 전사가 시작되는 레이스 컨디션**을 해결했다. Agora 녹화가 S3에 mp4로 합쳐지기 전 상태를 조회하면 HLS 재생목록(`.m3u8`)이 `recording_url`에 폴백 저장되는데, Gemini는 이를 읽지 못해 전사가 FAILED로 빠졌다. 스케줄러에서 `recording_url`이 누락되거나 mp4가 아닌 강의는 S3를 재탐색해 채우도록 개선했다.
- **Gemini File API 저장 용량(20GB) 초과로 전사 전체가 마비**되는 문제를 해결했다. 전사 후 Gemini에 업로드한 파일(`fileUri`)을 정리하지 않고 로컬 임시파일만 지우고 있었다 — `GeminiFileClient`에 `deleteFile()`을 추가하고, `TranscriptService`의 전사 성공/실패와 무관하게 `finally`에서 항상 호출되도록 해 외부 API의 유한 자원을 즉시 회수했다.
- **수업 정상 종료 시 복습용 문제 이미지가 S3에서 함께 삭제되는 부수효과 버그**를 고쳤다. 수업 완료 처리가 매칭 취소(`cancelMatching`) 경로를 그대로 타면서, "매칭 취소 시 문제 이미지 삭제"라는 로직이 정상 종료된 수업의 복습 썸네일까지 지워버렸다. "취소"와 "세션 정리"의 의미가 다르다는 점에 착안해, 이미지 삭제 없이 세션만 비우는 `clearSession()`을 분리해 정상 종료 흐름에 연결했다.

## 핵심 포인트

- 녹화 → 전사 → 요약 → PDF로 이어지는 무인 자동화 파이프라인 설계.
- Markdown→HTML→PDF 변환 체인에서 한글 폰트 임베드로 깨짐 문제 해결.
- 프롬프트 출력 제약(LaTeX/이모지 금지)으로 다운스트림 렌더링 안정성 확보.
- 비동기 단계 사이의 완료 시점 불일치(레이스 컨디션)를 재탐색 로직으로 흡수.
- 외부 API도 유한 자원(quota)이라는 관점에서, 사용 후 즉시 반납하는 정리 패턴을 finally에 강제.
- 같은 함수가 서로 다른 의미(취소 vs 정상 종료)로 재사용되며 생긴 부수효과 버그를 의미 단위로 분리.

## 관련 코드/도메인

- `backend/.../domain/lessonreview/` — `TranscriptScheduler`(폴링·재탐색), `TranscriptService`(전사·자원정리), `GeminiFileClient`(업로드/폴링/삭제), `LessonSummaryService`(요약·PDF)
- 엔티티: `lesson_transcript`(전사 텍스트 + 요약 PDF 상태/URL)
- 프롬프트: `backend/src/main/resources/prompts/` (lesson-transcribe, lesson-summary)
- 폰트: `backend/src/main/resources/fonts/NotoSansKR-*.ttf`
- 프론트: `StudentMatchingSessionNotifier.clearSession()`, `lesson_screen.dart`(수업 완료 분기)
