# 실시간 화상 강의

> Agora RTC 화상·음성 + 양방향 화이트보드 + 자동 녹화로 구성된 실시간 1:1 강의실.

## 한눈에 보기

| 항목 | 내용 |
|---|---|
| 화상·음성 | Agora RTC |
| 판서 | 양방향 화이트보드 (문제 이미지 배경 위 동시 필기) |
| 녹화 | Agora Cloud Recording (Web Page Recording) → S3 |
| 시간·과금 | 기본 30분(50코인) + 연장 10/20/30분, 최대 총 60분 |
| 정산 | 완료 후 24시간 보류 → 미신고 시 스케줄러가 확정 차감·정산 |
| API | `LessonController` 8개 (`/api/v1/lesson`) |

## 기능 흐름 (사용자 관점)

```mermaid
flowchart TB
    A["매칭 확정"] --> B["RTC 토큰 발급 (/token)"]
    B --> C["라이브룸 입장 (강사 · 학생)"]
    C --> D["화이트보드 판서 + 음성"]
    D --> E["자동 녹화"]
    E --> F["수업 완료 (/complete) → 질문 풀이완료 처리"]
    F --> G["24h 보류 후 코인 확정 차감 · 강사 정산"]
    F --> H["녹화본 → 복습 입력"]
```

## 주요 기능

- **화상·음성**: Agora RTC 기반 실시간 1:1 화상·음성.
- **양방향 화이트보드**: 문제 이미지를 배경으로 강사·학생이 동시에 필기. 5색 펜·지우개, 이미지 이동/확대, 핀치 줌 지원.
- **문제 이미지 업로드**: 수업 중 이미지 업로드(강의당 최대 10장). 프로파일별 저장(local=디스크, prod=S3).
- **자동 녹화**: 화이트보드 화면과 음성을 함께 녹화해 복습 자료의 입력으로 재활용.
- **시간 관리**: 기본 30분(50코인 선불 hold), 필요 시 연장(10/20/30분, 최대 총 60분). 연장 시 코인이 부족하면 hold 없이 부족액(`shortfallCoin`)을 돌려줘 강의 중단 없이 충전 후 재시도.
- **정산 연동**: 수업 완료 시 즉시 차감하지 않고 코인을 홀드 상태로 24시간 보류 — 그 사이 신고가 들어오면 정산을 막고, 미신고 건만 스케줄러가 확정 차감 후 강사에게 정산.
- **매칭 연동**: 수업 시작/종료 시 그 강사에게 신청해 둔 학생들에게 '수업 중/해제' 상태를 실시간 알림. 수업이 정상 완료되면 연결된 질문을 풀이 완료(RESOLVED)로 전이.
- **비정상 종료 정리**: 스케줄러가 24시간 넘게 방치된 진행 중/대기 강의를 자동 완료·취소 처리하고 강사의 매칭 가능 상태를 복구.

## API

기본 경로: `/api/v1/lesson`

| 메서드 | 경로 | 설명 |
|---|---|---|
| POST | `/token` | Agora RTC 토큰 발급 (채널 없으면 Lesson 자동 생성) |
| POST | `/{lessonId}/images` | 수업 중 임시 이미지 업로드 (최대 10장) |
| POST | `/{lessonId}/start` | 강의 시작 (코인 30분분 hold, 중복 호출 시 이중 hold 방지) |
| POST | `/{lessonId}/extend` | 강의 연장 (10/20/30분). 잔액 부족이면 `extended=false`+`shortfallCoin` 반환 → 충전 후 재호출 |
| POST | `/{lessonId}/complete` | 강의 완료 (질문 RESOLVED 전이 · 정산은 24h 보류 후 확정) |
| POST | `/{lessonId}/cancel` | 강의 취소 (묶어둔 코인 반환) |
| POST | `/{lessonId}/recording/start` | 녹화 시작 |
| POST | `/{lessonId}/recording/stop` | 녹화 중지 |
